## Decisions (from interview)
1. **Перезапуск тайлов**: убрать перезапуск одного тайла и простой перезапуск упавших. Добавить: «Пересчитать упавшие с новыми параметрами» (новая сессия) и «Пересчитать все с новыми параметрами» (новая сессия). Каждый пересчёт — новый job в проекте.
2. **«Карта высот растительности»** — заголовок раздела ЦММ в Древостое, не отдельный пункт. Под ним идут подпункты 1-6 (бывшие 5-10).
3. **Гари/Ветровалы** — убрать из СИМЫ полностью (не объединять). Весь блок «Дополнительные слои» в Forest убирается.
4. **Сглаживание/Разрешение**: выпадающий список предустановок + экспертные числовые поля.
5. **ЦМР vs карта рельефов (Древостой 1/2)**: два разных входа — ЦМР (DSM/DTM) + производные (уклоны/экспозиции/TPI).
6. **Результаты между проектами**: нет, только в рамках проекта.
7. **Размер тайла**: не выводим на пользователя нигде. Ошибка в ФТ. Работаем с тайлами из пар АФС+ВЛС.
8. **Горизонтали**: убрать только горизонтали, TIN оставить.
9. **Пользовательская СК**: будущее требование. СК считывается из метаданных файлов, делается основной, readOnly. Принудительное изменение невозможно.
10. **Git**: одна ветка, атомарные коммиты по логическим группам (~10 коммитов).

## Approach
10 групп коммитов:
1. types + store — обновление контрактов
2. ModuleHeader — общий компонент (СК readOnly, сглаживание, разрешение, тултипы, проверки зависимостей)
3. Upload — СК из метаданных, .geotiff ЦМР
4. Relief — убрать горизонтали, тултипы, ModuleHeader
5. Forest — два входа, убрать Плотность/Интенсивность/Размер тайла/Перекрытие/Оба метода/Доп.слои, Сезон→Состояние вегетации, таблица категорий рубки, ModuleHeader
6. Water — вход ЦМД, убрать Перекрытие/Разрешение/Болота/Охранные зоны/Размер тайла, ModuleHeader
7. Tasks — убрать перезапуск одного тайла и упавших, добавить Пересчитать упавшие/все с новыми параметрами
8. Data — просмотр параметров запуска
9. ProjectSettings — СК readOnly, убрать ручное изменение
10. Dependencies — блокировка расчёта при отсутствии данных предыдущих слоёв
